# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/mohmadhusenkhimani/Flutter_All_3MCA_Codes.git
```

---

## Open Project

```bash
cd Flutter_All_3MCA_Codes
```

Open using **Android Studio** or **VS Code**

---

## Install Packages

```bash
flutter pub get
```

---

## Run Application

```bash
flutter run
```
